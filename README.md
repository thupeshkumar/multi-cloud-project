# Multi cloud student project package

Start with `Installation_Guide.html` or `SETUP.md`. Complete the cost and eligibility checks before running Terraform. Use `Project_Submission.html` for the editable printable report, or edit `SUBMISSION.md`.

This is a starter implementation for VM and object-storage deployment with local monitoring and DNS failover. Optional managed databases use manual procedures. The guide and report identify the original assignment requirements that need further work. Nothing has been deployed by preparing this package.

Read `VALIDATION.md` for the checks performed and their limits. Cloud provider validation and real deployment tests remain to be run in your environment. Do not submit template placeholders as actual results.
